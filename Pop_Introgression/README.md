# Population Introgression Analyses

This folder contains workflows for detecting and summarizing introgression among Vitis populations.

## Contents

- `calculate_introgression_windows.sh`: computes window-based introgression statistics.
- `run_introgression_statistics.sh`: runs population-level introgression test workflows.
- `run_treemix.sh`: prepares and runs TreeMix migration graph analyses.
- `run_admixtools_introgression.sh`: prepares EIGENSTRAT input and runs ADMIXTOOLS/admixtools2 summaries.
- `vcf2treemix.sh`: converts VCF genotype data to TreeMix allele-count format.
