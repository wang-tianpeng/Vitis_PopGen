# Selection Sweep Workflows

This folder contains empirical and simulation-based selection-sweep workflows.

## Contents

- `run_sweed_selection_scan.sh`: runs SweeD across populations and chromosomes.
- `run_selection_sweeps.sh`: high-level sweep-analysis wrapper.
- `run_sweep_simulations.sh`: runs sweep simulations and simulation post-processing.
- `summarize_sweed_simulations.sh`: summarizes maximum CLR values from SweeD simulation outputs.
- `run_msprime_simulation_demography_v2.py`: msprime-based demographic simulation script.
- `generate_slurm_scripts_*.sh`: population-specific Slurm job generators for simulation batches.
